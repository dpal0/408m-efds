This is the unit test for EvalMetrics.cpp

Testing multiple edge cases for evalMetric.cpp. evalMetric is used to calculate 
the true positive, false positive, false negative, and true negative of the 
output.txt file after running multiple images into the graph cascade. 

Also evaluates the true positive rate or recall value, false positive rate, 
precision value, and F1 value of the output.txt file

Output.txt file in this case is shown as test1 to test8 .txt which are inputted 
into the evalMetric to test the calculated values for different edge cases.
