EFDS Tests
==========

This directory contains the test suite and evaluation runs for the EFDS.
Executables are built and installed here via makeme in efds/src/.

Directory Structure
-------------------

ITS Suites (run with dxtest)
    These follow the standard DICE ITS convention with runme scripts
    and can be exercised using the dxtest utility.

    Source_and_sink_tests/
        ITS suite for the iis_source and iis_sink actors.
        Driver: test_source_sink.exe

    Classifier_actor_tests/
        ITS suite for the classifierActor.
        Driver: classifier_actor_driver.exe

    Graph_tests/
        ITS suite for the full EFDS graph pipeline.
        Driver: efds_graph_driver.exe

    test_evalMetrics/ and test-utils-evalmetrics/
        ITS suite for the EvalMetrics utility.
        Driver: evalTrain_driver.exe

    Per_stage_summary/
        Classifier config files representing the current best trained cascade.
        Used as the default config dir by runme and runme_latency.sh.
        One .txt file per stage (stage0.txt, stage1.txt, ...).

    Sweep_accuracy_metrics.txt
        Aggregated accuracy results (Recall, Precision, F1, FPR) across all
        test_trainN configurations. Generated by sweep_eval.sh.

Evaluation Runs (not ITS)
    These are design space exploration runs using different classifier
    configurations. Each has a runme_eval script instead of a runme,
    and is not intended to be exercised with dxtest.

    test_train0/ - test_train6/
        Evaluation runs with different config files to explore
        trade-offs in detection rate, false positive rate, and
        processing speed.

    train_narrow/
        Evaluation run with a narrow (more restrictive) cascade config.

    train_normal/
        Evaluation run with a normal cascade config.

     train_wide/
        Evaluation run with a wide cascade config.

Installed Executables
---------------------

    test_source_sink.exe       - used by Source_and_sink_tests/
    classifier_actor_driver.exe - used by Classifier_actor_tests/  (in Classifier_actor_tests/)
    efds_graph_driver.exe      - used by Graph_tests/ and evaluation runs
    evalTrain_driver.exe       - used by test_evalMetrics/

Utilities and Scripts
---------

    cleanup.sh
        Removes generated output files (face.txt, non-face.txt,
        temp_face.txt, temp_non-face.txt, nf*.txt) from all test_*/
        subdirectories. Run from this directory:

        Usage:
            ./cleanup.sh
    
    runme_latency.sh
         Captures timing output for latency benchmarking on the host server. Sotres them as csv files in Per_stage_summary/
 
        Usage:
            ./runme_latency.sh <config file name>

            eg: ./runme_latency.sh narrow

    runme_subchain.sh
        Runs the EFDS using only the first k stages of the cascade (k = 1, 2, ..., N),
        recording accuracy and latency for each sub-chain. Stores them as csv files in Per_stage_summary/
 
    Usage:
        ./runme_subchain.sh <config file name>

        eg: ./runme_subchain narrow

    sweep_eval.sh
        Sweeps over all test_trainN configurations, runs the EFDS on each, computes
        EvalMetrics for each, and appends results to Sweep_accuracy_metrics.txt.
        Used for the performance-vs-accuracy Pareto plot.
 
    Usage:
        ./sweep_eval.sh

Workflow
----------------
1. Build everything from efds/src/:
       ./buildsetup   # first time only
       ./makeme       # compiles + installs executables into efds/tests/
 
2. Run unit tests: (If needed)
       cd Classifier_actor_tests/ && dxtest
 
3. Run a full graph integration test:
       cd Graph_tests/test01 && ./runme_eval
 
4. Sweep all training configurations and collect metrics:
       cd efds/tests && ./sweep_eval.sh
 
5. Generate sub-chain trade-off data for the report:
       ./runme_subchain.sh Per_stage_summary/ <input_dir> <ground_truth_file>
 
6. Clean up generated output files:
       ./cleanup.sh
